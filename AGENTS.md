# Notunayon — AI Agent Instructions

## Project
An agricultural biomass waste-to-energy marketplace connecting waste producers with businesses that reuse agricultural by-products.

## Technology Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js, CommonJS
- Database: MySQL 8.4
- ORM: Prisma 7
- AI: Gemini API

## Structure
- /src — Frontend
- /public — Frontend assets
- /backend — Backend application
- /docs — Documentation

## Rules
1. Inspect existing code before modifying it.
2. Never change the stack without approval.
3. Never modify SaveBite or its database.
4. Never expose or commit secrets.
5. Never overwrite another developer's work.
6. Keep frontend and backend API contracts aligned.
7. Test changes before reporting completion.
8. Document unfinished work and decisions.
9. Use descriptive Git commits.
10. Never run destructive database operations without approval.
